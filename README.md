This is the publicly available GitHub repository for the manuscript "Changes in Listing Behavior Following the OPTN’s Sep. 2025 Status 2 Device Requirement Amendment". All code for data cleaning, analyses, and figure/table generation can be found within this repository. To reproduce the analyses, one must have access to the complete SRTR Standard Analysis Files and Heart Justification Files. Both databases can be obtained through data use agreements (typically requiring a priori IRB approval) with the SRTR, respectively.

The "markdown_table_1.Rmd" file constructs the seasonally matched pre- and post-policy cohorts and produces Table 1. The table reports candidate demographics, initial listing status, and five allocation criteria at listing derived from justification form qualifications and device implant records, with Wilcoxon rank-sum tests for continuous variables and Pearson chi-squared tests for categorical variables.
